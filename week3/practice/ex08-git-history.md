# 提交信息对比

较强示例：e1a47a8 docs: add week2 experiment report and exercises。主题包含改动范围和产物，
读者可快速定位到周次、文档与练习三个关键信息。

较弱示例：9983913 add gitignore。主题只说明修改了 .gitignore，未解释忽略哪些产物、
为何需要忽略。更完整的写法可为：

chore: ignore generated build and local environment artifacts

Prevent editor, LaTeX, Python cache, and local virtual-environment files
from polluting future commits while keeping the intended course artifacts tracked.
