# README 对比

选取 FastAPI、Requests 和 Rich 的 GitHub README 进行结构对比。

| 项目 | 信息层次 | 值得借鉴之处 |
|---|---|---|
| FastAPI | 首屏定位、核心特性、示例与文档入口 | 用极短示例让读者快速判断是否适用 |
| Requests | 一句话用途、安装、快速使用、文档链接 | 安装与最常见调用路径清楚且紧凑 |
| Rich | 视觉示例、功能分类、安装与链接 | 通过终端效果图降低理解成本 |

三者共同点是先回答“它做什么”和“如何开始”，再逐步提供更细的文档链接；这与课程提出的
README 漏斗式结构一致。
